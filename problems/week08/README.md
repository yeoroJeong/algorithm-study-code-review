# 8주차: 각자 선정한 문제 풀이·설명

- **진행 기간:** 2026-09-28 ~ 2026-10-04
- **모임 일시·제출 마감:** 확정 후 공지
- **목표:** 스터디원마다 문제를 1개 이상 직접 선정해 풀고, 스터디에서 해당 문제와 풀이를 설명합니다.

## 참여 방법

1. 문제 사이트·난이도·언어에 제한 없이 문제를 선정합니다. 여러 문제를 선정해도 됩니다.
2. [노션 8주차](https://app.notion.com/p/3a6d0503fdff8192aa6ee19f6d0b904d)의 문제 풀이 보드에 문제 제목과 링크, 담당자를 등록합니다.
3. 풀이 코드를 이 저장소에 제출합니다. 문제별 폴더명은 `사이트_문제번호`를 권장합니다. 번호가 없으면 식별 가능한 영문 이름을 사용합니다.
4. 스터디에서 문제 요약, 핵심 아이디어, 시간·공간 복잡도, 구현 시 주의할 점을 설명합니다. 풀지 못했다면 시도한 접근과 막힌 지점을 공유합니다.
5. 발표 후 질문과 코드 리뷰를 진행합니다.

### 발표 및 리뷰 포인트

- algo1: `0` 빈칸, `1` 벽, `2` 출구, `3` 시작점으로 해석합니다. 동일 좌표도 남은 벽 파괴 횟수에 따라 다른 상태입니다. BFS 최초 출구 도달이 최단 거리이며 시간·공간은 O(N*M)입니다.
- algo1 수정: `ans = -1`일 때 `cnt >= ans`가 처음부터 참이어서 0을 출력하던 종료 조건을 제거했습니다. 시작점은 실제 시작 상태인 `visited[1]`만 표시합니다.
- algo2: 팀원 순서대로 미배정 업무를 선택합니다. 값 0은 배정 불가이며 양수 비용을 누적하고 `cost >= ans`이면 중단합니다. 배정 불가능하면 -1을 출력합니다.
- algo2 복잡도: 최악의 순열 탐색은 O(N!), 리스트 슬라이싱을 포함한 보수적 시간 상한은 O(N*N!), 공간은 입력과 재귀 중 리스트를 포함해 O(N^2)입니다. 원문 N 제한이 없어 시간 제한 통과 여부는 확인하지 못했습니다.
- 공식 채점 통과 여부는 미확인입니다. 로컬 테스트 결과는 PR에 기록합니다. 테스트 실행: `python -m unittest discover -s tests -p test_week08_solutions.py`.
